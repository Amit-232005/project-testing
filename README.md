# Competitive Programming Solutions

A collection of competitive programming solutions written in **Python** and **Java**. The repository primarily contains practice solutions for Codeforces-style problems, recursion exercises, contest problems, dynamic programming, and CSES problems.

## Repository Structure

```text
.
└── Codeforces/
    ├── Contests/                 # Contest and practice solutions
    ├── Sheet 7 Recursion/        # Recursion and basic problem-solving exercises
    ├── Zuma_607B.java            # Dynamic programming solution for Zuma (607B)
    ├── test.py                   # Python practice and problem solutions
    └── tempCodeRunnerFile.*      # Temporary editor-runner files
```

## Topics Covered

- Arrays and matrix operations
- Prefix and suffix sums
- Recursion and backtracking
- Factorial, Fibonacci, and exponentiation
- Combinations and number of ways
- Dynamic programming
- Knapsack problems
- Palindromes and string operations
- Contest problem solutions
- Java and Python implementations

## Languages

- **Python** — the majority of the practice solutions
- **Java** — recursion, dynamic programming, CSES, and Codeforces solutions

## Running a Solution

### Python

Python 3 is required.

```bash
python3 "Codeforces/test.py"
```

Replace the file path with the Python solution you want to run.

### Java

Use a JDK and compile the desired source file:

```bash
javac "Codeforces/Zuma_607B.java"
java Zuma_607B
```

Run Java files from their containing directory if the source file depends on relative paths or a specific package layout.

## Notes

- Each source file is generally standalone and can be tested independently.
- The repository includes compiled `.class` files created during Java development.
- Some files are temporary editor or debugging files and may not represent complete projects.
- Input is commonly read from standard input, and output is printed to standard output.
